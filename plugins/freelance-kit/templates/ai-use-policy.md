# AI-use tiers (agree one per client, record it in the client's notes.md)
1. **Confidential**: the client's own Anthropic API key or Claude Team seat. Nothing runs on the freelancer's personal subscription.
2. **Standard**: the freelancer's own commercial API key (no model training by default), cost billed back.
3. **Public / non-confidential**: personal subscription with the model-training setting off.

Disclose AI-assisted development in the contract and list Anthropic as a subprocessor for tiers 1-2.
Background: Anthropic's data-usage and legal pages (code.claude.com/docs/en/data-usage, code.claude.com/docs/en/legal-and-compliance).
