# Instructions for AI agents

- To set up the agentic workflow from this repository for a person, follow [SETUP.md](SETUP.md).
- To change this repository, follow [CONTRIBUTING.md](CONTRIBUTING.md): run `python scripts/validate_skills.py` and the tests before you finish, use Conventional Commits, and add a line under `## [Unreleased]` in the CHANGELOG.
- Keep private data out: no real names other than the maintainer's, no emails, keys, home-directory paths, employer or client details.
