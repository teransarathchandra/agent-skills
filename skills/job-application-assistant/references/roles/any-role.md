# Role profile: any other role (fallback)

## When to use this

Load this when no other file in this folder matches the person's role, for example a nurse, teacher, electrician, lawyer, driver or chef. Do not force the person into a near family: a wrong profile gives wrong keywords and wrong screening answers.

## Build the profile for this session

1. Ask for the person's job title and the countries they will apply in.
2. Ask for five recent, real ads for that title in those countries. The person pastes or links them; do not invent ads. If fewer than five can be found, say so and use what exists.
3. Ask for the person's evidence: where proof of the work lives, and what can be shown versus what stays private (patients, clients, pupils, employers, licences).
4. Fill the nine family sections for this session, from the ads and the person's answers:
   - Titles and adjacent roles, with realistic moves for a laid-off person.
   - Evidence sources, split into public and private.
   - Intake questions: three to six, each with options, a recommended answer first and "Other: type it" last; "answer as it is" for facts.
   - CV shape: section order, summary lead, strong bullets with fictional examples.
   - Keywords and credentials: keywords repeated across the ads, and credentials or licences only where the ads or the issuer's own page show them. Name the issuing body and country; never say something is required unless the ads show it.
   - Portfolio or work samples: whether the ads expect one.
   - Screening questions the ads ask, and how to answer them from the answer bank.
   - Answer-bank `experience` keys: lowercase tools, methods and credentials.
   - Mistakes to avoid.
5. Write norms as patterns from the ads ("most of the five ads ask for..."), never as rules.
6. Set `"role_family": "any-role"` in the answer bank, with `"experience": {"total_years": N, "items": {...}}` in the usual format.

## Where it is kept

Save the filled profile in the person's private working folder, with the rest of their application files. Never write it into the skill's own files, and never include it in anything published or shared. Next session, reload it from that folder and ask whether the ads still match before reusing it.
