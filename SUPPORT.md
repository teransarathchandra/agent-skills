# Support

- **A skill gave a wrong, unsafe or confusing result:** open a [bug report](https://github.com/teransarathchandra/agent-skills/issues/new?template=bug_report.yml). Do not paste private data.
- **You want a new skill, or a change to one:** open a [skill idea](https://github.com/teransarathchandra/agent-skills/issues/new?template=new_skill.yml).
- **You found a security problem:** report it privately through [security advisories](https://github.com/teransarathchandra/agent-skills/security/advisories/new). See [SECURITY.md](SECURITY.md).
- **You want to contribute:** read [CONTRIBUTING.md](CONTRIBUTING.md).

This is a one-maintainer project. Issues are read, but replies can take a few days.
